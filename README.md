# Racha a Conta

Calculadora para dividir a conta do bar entre os amigos, com valores em reais (R$).

## O que ela faz

- Divide a bebida alcoólica só entre quem bebeu.
- Aplica a taxa de serviço proporcional ao consumo de cada pessoa e soma o couvert por pessoa.
- Fecha o total exato, centavo por centavo.
- Permite escolher quem pagou a conta e informar a chave Pix dessa pessoa.
- Gera uma mensagem de cobrança pronta para cada pessoa, com o botão **Copiar cobrança**.
- Copia a divisão completa para colar no grupo.

## Como abrir

É um único arquivo `index.html`, sem dependências. Abra direto no navegador ou acesse pelo GitHub Pages. Os dados ficam salvos só no navegador de quem usa.
